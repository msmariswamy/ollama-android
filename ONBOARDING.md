### Skills to Know About
- `/opsx:propose` — Propose a new feature change: generates a proposal, design doc, specs, and task list in one step. Use this before starting any new feature or fix.
- `/opsx:apply` — Work through implementation tasks from an existing openspec change. Run this after `/opsx:propose` to start coding.
- `/opsx:archive` — Archive a completed change after all tasks are done. Syncs delta specs back to main specs and moves the change to the archive folder.
- `/opsx:explore` — Think through an idea or investigate a problem before proposing. Good for ambiguous situations where you're not sure what to build yet.
- `/clear` — Clear the conversation context. Use between unrelated tasks to avoid context bleed.
